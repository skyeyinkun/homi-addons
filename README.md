# HOMI Add-ons

HOMI 是一款运行在 Home Assistant 本地环境中的家庭控制面板，用于在一个界面中查看和控制已接入 Home Assistant 的家中设备，适配手机、平板、桌面及 HA 侧边栏等多种访问方式。功能的实际表现取决于你的 HA 环境、设备与网络状况。

本仓库是 HOMI 的 Home Assistant 加载项**分发仓库**（仅包含安装配置与文档，不含源代码）。

HOMI 是 Home Assistant 生态的第三方软件，不是 Home Assistant 官方项目，也不代表 Home Assistant 官方背书、认证或支持。

## 安装方法（只需操作一次）

1. 打开 Home Assistant → **设置 → 加载项 → 加载项商店**
2. 点击右上角 **⋮** → **仓库**，粘贴以下地址并添加：

   ```
   https://github.com/skyeyinkun/homi-addons
   ```

3. 在商店中找到 **HOMI** → 点击 **安装**
4. **启动**加载项，然后选择一种入口：
   - 推荐：从 HA 左侧栏点击 **HOMI**，或点击加载项页面的 **打开 Web UI**，通过 Home Assistant Ingress 访问
   - 内网独立页面：默认可通过 `http://HA主机IP:8099/` 访问，仅限可信局域网
5. 首次安装无论从哪个入口进入，都必须在授权页**复制申请码**发给卖家，取得有效**授权码**后粘贴激活
6. 当前 HOMI 实例保持有效授权时，后续从 Ingress 或 `8099` 进入都不再要求授权码、Core 配对令牌或安全 PIN
7. 若卖家发布新版本，商店里的 HOMI 卡片会显示 **更新** 按钮，可由用户自行决定是否更新；本说明不承诺更新频率或持续期限

> `8099` 上的设备控制不经过 Home Assistant 登录页。只应在你信任的局域网中使用；禁止进行路由器端口转发，也不要通过公网反向代理暴露该端口。

## 提供镜像的设备架构

- `amd64`：x86 电脑、N5105 等软路由/小主机
- `aarch64`：树莓派 4/5、大部分 ARM64 设备（HA Green、HA Yellow 等）
- `armv7`：树莓派 3 等 32 位 ARM 设备

当前仅在真实 Home Assistant Green（`aarch64`）上确认运行。`amd64` 和 `armv7` 已提供对应镜像，但尚未完成真实硬件安装验收，不能据此理解为所有同架构设备都已验证兼容。

HOMI 2.0.1 已在 Home Assistant Green 上完成同一运行实例的内置备份恢复验证；完整 Home Assistant 备份恢复、重装、断电和其他架构场景仍未验证。内置备份不能替代 Home Assistant 原生备份，也不代表对恢复结果作出承诺。
