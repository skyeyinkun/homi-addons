# HOMI Add-on 更新日志

## 1.3.14（2026-08-02）

- 加强发布安全门禁，自动拦截构建产物中的 GitHub、OpenAI、AWS 和硬编码 Bearer 凭据，同时避免在日志中回显敏感值。
- 清理并忽略开发工具会话产物，防止设计草稿、运行状态或调试信息被误提交。

## 1.3.13（2026-08-02）

- 收拢首页顶部状态区与右侧操作按钮，使电脑网页和横竖屏平板端与首页卡片画布左右边界一致；APP 手机端布局保持不变。

## 1.3.12（2026-08-02）

- Add-on 默认开放可信内网独立访问端口 `8099`；完成首次机器码授权后，独立页面不再要求重复授权、Core 配对令牌或安全 PIN。
- 保留首次产品授权与 Standalone Core/Docker 的原有安全边界，并明确禁止将 `8099` 端口转发或代理到公网。
- 修复手机端调整首页卡片后电脑端布局混乱的问题；2、3、4、5 列位置分别保存，卡片配置仍由同一 Core 统一同步与备份。

## 1.3.11（2026-08-01）

- 优化设备页顶部布局，使左侧标题和右侧管理按钮与设备筛选、卡片内容区两侧对齐。
- 修复设备快速编辑抽屉的拖拽手势干扰实体绑定操作的问题，展开和选择实体时保持正常交互。

## 1.3.10（2026-08-01）

- 修复 GitHub 发布机器时区不同导致的前端单元测试失败，保证中国时区下的更新时间显示测试稳定。
- 修复 Node.js 20 环境中的授权验签数据兼容问题，避免有效授权在发布测试中被误判。
- 公开更新仓库改为同步完整安装配置，确保端口、安全说明和版本号始终与正式镜像一致。

## 1.3.9（2026-08-01）

- 默认仅通过 Home Assistant Ingress 安全访问，不再自动开放局域网 `8099` 端口；直连请求必须经过 HOMI Core 配对认证。
- 加强敏感设备操作保护：PIN 验证增加旧 PIN 校验、失败限速和一次性操作授权，并防止重复提交。
- 提升配置与备份可靠性：私密文件改为原子写入，恢复前完整校验，失败时自动回滚，避免部分数据被覆盖。
- 加强 AI 服务请求保护：禁止跳转到其他地址，并限制总请求时长和返回大小。
- 修复首次配置和设置窗口自动化测试，补齐版本、构建、Add-on、布局和浏览器发布门禁。
- 移除不再维护的更新诊断入口；版本更新统一由 Home Assistant 加载项商店和 GitHub Release 提供。

## 1.3.8（2026-08-01）

- 更新诊断新增 HA 主机网络状态识别：当 Supervisor 判定主机或自身无法联网时，直接提示网络原因并阻止无效刷新。
- 信息容器总电量等能耗单位统一显示为短格式 `kWh`，避免“千瓦时”等长单位挤占数值显示。
- 修复信息容器配置候选范围：仅允许数值/传感器类展示实体，开关、灯光、调光、空调、按钮等控制类实体不会出现在推荐或搜索结果中。

## 1.3.7（2026-07-31）

- 首页和房间页进入编辑/管理模式后，切换到其它页面会自动退出编辑态，避免返回页面后仍停留在编辑状态。
- 首页和房间页支持点击空白区域退出编辑态，同时保留按钮、筛选、设备卡片和拖拽手柄的正常操作。
- 优化空调运行态图标阴影表现，减少雪花图标在运行/未运行状态切换时的视觉突兀。

## 1.3.6（2026-07-31）

- 设备配置的“已添加”视图新增批量选择，可按当前搜索和类型筛选结果全选，并通过二次确认快速取消绑定。
- 取消绑定时同步清理设备记录、Home Assistant 实体映射和对应首页设备卡片；解绑实体不会被忽略，后续仍可重新绑定。

## 1.3.5（2026-07-30）

- 修复设备名称关键词覆盖 Home Assistant 实体域导致的误分类问题，例如空调控制、门锁开关、窗帘开关、扫地机器人开关等。
- 已保存的历史错误设备会在同步时自动迁移到正确类型，并保留用户自定义名称和图标。
- 完善自动发现、实体映射校验和跨设备类型回归测试，避免错误分类影响卡片和控制入口。

## 1.3.4（2026-07-29）

- 优化 HA `button` / `input_button` 无状态按钮卡片：控制入口统一为开关/插座类卡片的右上角控制样式，但不显示持续开关状态；离线时不会触发动作。
- 移除 HA 报警面板/安防系统的独立设备卡片展示，旧首页模块和新增设备卡片候选中不再显示该类卡片。
- 移除设备卡片选择中的“安防”类型筛选；门锁、门磁、窗磁、烟感、燃气、水浸等其它设备展示不受影响。

## 1.3.3（2026-07-29）

- 首页布局改为 HA 主机统一保存的一套配置，Ingress、独立网页、手机与平板不再分别维护布局副本；不同屏幕仅做自适应排列。
- 修复首页布局修改未进入服务端增量同步队列的问题，并防止旧浏览器缓存覆盖主机上的最新配置。
- 完善备份恢复闭环：备份包含统一布局与共享配置，恢复时清除旧缓存和待上传数据，并自动重新加载恢复后的配置。

## 1.3.2（2026-07-28）

- 优化全系统字体策略：停止优先使用不完整内置字体，改用系统中文字体栈，减少“门关”等中文字符字形异常。
- 修复 HA `button` / `input_button` 历史设备数据可能仍按开关展示的问题；旧开关映射到无状态按钮时会自动迁移为按钮卡片。
- 完善按钮设备的筛选、同步和控制链路，点击按钮统一调用 Home Assistant `press` 服务，不显示开关状态。

## 1.3.1（2026-07-28）

- 修复 HOMI 已完成系统配置后，重新进入或刷新页面仍回到系统配置页的问题；已配置用户优先进入首页。
- 优化设备页顶部筛选栏宽度，使其与下方设备卡片两侧边距保持一致。
- 全系统统一内置字体粗细策略，减少同一段文字粗细不一致的问题。

## 1.3.0（2026-07-28）

- 修复系统配置中修改设备名称、图标后保存未同步的问题；扫描、设备配置、首页卡片和房间管理列表统一生效。
- 新增 HA `button` / `input_button` 无状态按钮设备支持，按触发型设备展示和调用。
- 优化安防类卡片与设备分类展示，提升门锁、报警、传感器等设备的识别和控制体验。
- 统一内置界面字体资源，减少不同页面文字风格不一致的问题。

## 1.2.9（2026-07-27）

- 重新发布：刷新 Home Assistant 加载项商店的更新元数据，功能与 1.2.8 保持一致。

## 1.2.8（2026-07-27）

- 加载项配置页精简：移除三项不常用的高级配置项，保持默认即可正常使用。
- 系统配置 · 授权：已授权设备自动回填授权码并默认掩码显示（可按需查看）；授权信息默认折叠；激活按钮按需显示。
- 动态背景模式：选中项增加更清晰的选中指示。

## 1.2.7（2026-07-26）

首个通过官方加载项仓库发布的版本。添加仓库安装后，后续新版本可在 Home Assistant 加载项商店中直接提示并一键更新。

**主要内容**

- 家庭控制面板：在一个界面中查看和控制已接入 Home Assistant 的设备，适配手机、平板、桌面与 HA 侧边栏。
- 独立端口访问：默认开放 `8099` 端口，可浏览器直连使用，提供可选的 PIN 解锁。
- 首页设备运行概览：含电池电量等信息（以设备实际上报为准）。
- AI 助手：本地规则应答，可自行配置兼容 OpenAI 接口的模型服务。
- 摄像头画面查看（以 HA 实体的实际支持情况为准）。
- 授权管理、配置备份与恢复。
- 多端布局与显示设置（含动态背景开关）。

功能的实际表现取决于你的 Home Assistant 环境、设备与网络状况。

**支持架构**：amd64 / aarch64 / armv7
