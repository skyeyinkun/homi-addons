# HOMI Add-on 更新日志

## 1.2.7 首个公开发布版（2026-07-26）

HOMI 首个通过官方加载项仓库公开发布的版本。添加仓库后安装，后续新版本会在 Home Assistant 加载项商店直接提示"更新"，一键升级。

**核心能力**

- 多端家庭控制界面：设备、房间、模式、人员、摄像头、天气、AI 助手、授权与备份统一管理，适配手机、平板、桌面、墙屏与 HA 侧边栏。
- 独立端口访问：默认开放 `8099` 端口，浏览器直连 `http://<HA主机IP>:8099` 全屏使用，可选 PIN 解锁保护。
- 首页设备运行统计：电池电量等状态实时统计，低电量设备主动上报。
- AI 助手：本地快速查询基于实时数据，快捷查询标签按家庭设备情况智能推荐，支持 OpenAI-compatible 模型代理。
- 摄像头播放：HA 原生 WebRTC 主路 + HLS 自动回落，支持萤石云代理。
- 离线授权：设备指纹绑定、后端验签，重装可自助恢复。
- 备份与恢复：本机备份、下载、导入恢复，恢复前自动快照。
- 动态背景可开关，低性能设备更流畅。

**支持架构**：amd64 / aarch64 / armv7
