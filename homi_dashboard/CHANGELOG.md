# HOMI 1.0.7

## 新增与修复（2026-08-20）

- 设备运行状态支持自由调整灯光、开关、空调、窗帘、人体检测和电池提醒的显示顺序。
- 排序方式与信息容器保持一致，支持置顶、上移、下移和置底，并在刷新后保留设置。
- 修复仅保留电池提醒时其他运行类型被错误恢复显示的问题。
