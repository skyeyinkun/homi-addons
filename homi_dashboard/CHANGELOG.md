# HOMI 1.0.33

## 新增与优化（2026-11-23）

- 专业版恢复 Home Assistant 摄像头发现、房间分类和首页模块。按需开启预览，支持 WebRTC、HLS 和快照回退，保留已有摄像头配置。
- AI 助手合并流式文字刷新。可在助手设置中开启语音回复朗读，使用设备上的本地中文音色，默认关闭。
- 补齐彩灯颜色、白光、设备色温和灯效控制，按灯具能力显示选项。修复设备状态刷新覆盖较新反馈、窗帘开度能力判断和跨屏新增卡片挤动已保存布局的问题。
- 天气缺少真实数据时显示不可用状态或有效缓存，移除示例天气和固定空气质量读数。
- 继续使用机器码和授权码激活 HOMI，现有授权和配置沿用当前机制。

# HOMI 1.0.31

## 新增与优化（2026-09-29）

- 迁入 HAIOTS AI 助手界面与交互，支持本地助手、大模型助手、Home Assistant 官方助手三种模式。
- 增加官方助手列表、会话与后端代理接入，保留 PIN 安全确认；取消、断线和超时不会自动重发控制指令。
- 增加长按说话、滑动取消与文字预览；浏览器语音需要 HTTPS 或 localhost，并取决于浏览器的语音识别支持。
- 按主机隔离助手配置、聊天和告警历史，修复主机切换及多标签页配置更新问题，避免本机告警被远端同步覆盖。
- 调整页面外部标题、分类和数量统计的文字层级，保持设备卡片与实体卡片内部字号不变。
- 本次含加载项后端变更，请完整更新加载项；仅替换前端 dist 不会启用新增的官方助手代理。

# HOMI 1.0.30

## 新增与优化（2026-08-31）

- 新增黑色主题天气卡片背景，支持晴朗、夜晚、多云、阴天、雾、雨、雪和雷暴等状态自动切换。
- 优化天气卡片的信息布局，地点、温度、体感和日期与卡片光效分隔线统一对齐。
- 优化黑色主题的环境光、卡片材质和状态光效，保持原有布局与交互不变。
- 保留实时地点、温度、日期和天气详情；浅色主题继续使用原有天气卡片样式。
