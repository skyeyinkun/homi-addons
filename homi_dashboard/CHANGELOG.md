# HOMI Add-on 更新日志

## 2.0.0（2026-08-04）

HOMI 正式发布。

- 提供适配手机、平板、桌面浏览器和墙屏的 Home Assistant 家庭控制界面。
- 支持设备自动发现、房间与人员管理、摄像头查看、场景控制、AI 助手和本地备份恢复。
- 首页与设备卡片采用响应式布局；扫地机器人卡片显示状态、更新时间和四个重要参数，并在不同屏幕尺寸下保持完整显示。
- 支持 Home Assistant Ingress 和默认开放的可信内网 `8099` 独立页面；首次进入仍须完成机器码授权，当前实例保持有效授权时后续无需重复输入。
- 采用本地离线授权和机器绑定机制；除用户主动发给卖家的授权申请码外，家庭设备数据、摄像头画面及 Home Assistant 凭据默认不经过开发者云端。

功能表现取决于实际 Home Assistant 环境、设备能力、网络状况及用户自行配置的第三方服务。

当前已在 Home Assistant Green（`aarch64`）真实环境确认运行。`amd64` 和 `armv7` 提供镜像但尚未完成真实硬件安装验收；内置备份恢复也尚未完成真实恢复验收。软件按现状提供，本版本说明不承诺持续更新、换机重签或固定售后范围。

**支持架构**：amd64 / aarch64 / armv7
