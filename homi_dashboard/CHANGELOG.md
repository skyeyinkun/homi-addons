# HOMI Add-on 更新日志

## 1.2.7（2026-07-26）

首个通过官方加载项仓库发布的版本。添加仓库安装后，后续新版本可在 Home Assistant 加载项商店中直接提示并一键更新。

**主要内容**

- 家庭控制面板：在一个界面中查看和控制已接入 Home Assistant 的设备，适配手机、平板、桌面与 HA 侧边栏。
- 独立端口访问：默认开放 `8099` 端口，可浏览器直连使用，提供可选的 PIN 解锁。
- 首页设备运行概览：含电池电量等信息（以设备实际上报为准）。
- AI 助手：本地规则应答，可自行配置兼容 OpenAI 接口的模型服务。
- 摄像头画面查看（以 HA 实体的实际支持情况为准）。
- 授权管理、配置备份与恢复。
- 多端布局与显示设置（含动态背景开关）。

功能的实际表现取决于你的 Home Assistant 环境、设备与网络状况。

**支持架构**：amd64 / aarch64 / armv7
