# HOMI Add-on

## 简介

HOMI 是一款运行在 Home Assistant 本地环境中的家庭控制面板，用于在一个界面中查看和控制家中设备，适配手机、平板、桌面及 HA 侧边栏等多种访问方式。

面板配置保存在安装它的 Home Assistant 主机上，完成一次初始化后，同一网络内的多台设备可共用这份配置。

## 安装

1. 打开 Home Assistant → **设置 → 加载项 → 加载项商店**。
2. 点击右上角 **⋮ → 仓库**，添加 HOMI 仓库地址（购买时由卖家提供）。
3. 在商店中找到 **HOMI** → 点击 **安装**。
4. **启动** HOMI。一般无需修改任何配置，保持默认即可。
5. 通过 HA 左侧栏 / **打开 Web UI** 进入；也可以在可信内网打开 `http://HA主机IP:8099/`。
6. 首次进入在授权页复制申请码并发给卖家，取得有效授权码后粘贴激活。

若卖家发布新版本，商店中的 HOMI 卡片会显示 **更新** 按钮，可由用户自行决定是否更新；本说明不承诺更新频率或持续期限。更新前应先创建 Home Assistant 原生备份。

## 访问方式

HOMI 同时支持 Home Assistant Ingress（HA 左侧栏或“打开 Web UI”）和默认开放的内网独立端口 `8099`。

- 请优先使用 Ingress，它会沿用 Home Assistant 的登录和访问边界。
- 首次安装无论从哪个入口进入，都必须使用机器码和有效授权码完成产品激活。
- 当前 HOMI 实例保持有效授权时，后续从 Ingress 或 Add-on 内网独立页面进入都不再要求授权码、Core 配对令牌或安全 PIN。
- 内网中能连接 `8099` 的设备可以操作 HOMI。不要进行路由器端口转发，也不要通过公网反向代理暴露该端口。
- 上述免配对规则只适用于 Home Assistant Add-on；独立 Core/Docker 的局域网访问仍必须配置 `HOMI_CORE_ACCESS_TOKEN`。

## 主要功能

- 查看和控制已接入 Home Assistant 的设备（灯光、窗帘、空调、媒体等，以 HA 实际接入情况为准）。
- 首页设备运行概览（含电池电量等信息，以设备实际上报为准）。
- AI 助手：支持本地规则应答，也可自行配置兼容 OpenAI 接口的模型服务（需自备服务与 Key）。
- 授权管理，以及无需备份密码的 HOMI 完整备份与恢复。备份包含 HOMI 配置、HA 连接、AI Key、安全 PIN 和授权，请仅保存在可信位置；它不等于 Home Assistant 原生整机备份，更新或重装前仍应另外创建 HA 原生备份。
- 多端布局与显示设置（含动态背景开关）。

功能的实际表现取决于你的 Home Assistant 环境、设备厂商与网络状况，无法逐一保证。

## 权限说明

- `hassio_api` / `hassio_role: manager`：仅用于授权校验所需的设备指纹采集。Add-on 通过 Supervisor API 读取本机网络与系统信息（`/network/info`、`/os/info`、`/host/info`），原始值仅在本机处理，不会自动上传。系统会生成机器码和哈希因子并组成申请码；只有用户主动把申请码发给卖家时，这些派生值才会离开本机，用于签发授权码。

## 数据说明

- Add-on 通过 Supervisor 运行时令牌连接当前 Home Assistant，不要求创建长期访问令牌。
- 在面板中填写的 AI Key 仅保存在本机，不以明文回传给前端页面。安全 PIN 只用于独立 Core/Docker 模式；Home Assistant Add-on 的 `8099` 内网独立页面不要求 PIN。
