# HOMI Add-on

## 版本

- 当前版本：1.2.7（首个公开发布版）
- 推荐入口：Home Assistant 左侧栏 / Add-on Web UI / 浏览器直连 8099 端口

## 简介

HOMI 是运行在 Home Assistant 本地环境中的多端家庭控制界面。它把设备、房间、模式、人员、摄像头、天气、AI 助手、授权和备份集中到一个适合手机、平板、桌面、墙屏和 HA 侧边栏使用的界面中。

HOMI Add-on Core 会在同一台 Home Assistant 主机上统一保存授权、HA 连接、AI、设备、房间、人员、场景和布局配置。完成一次初始化后，手机、平板和网页端可共享同一份配置。

## 安装

1. 打开 Home Assistant → **设置 → 加载项 → 加载项商店**。
2. 点击右上角 **⋮ → 仓库**，添加 HOMI 官方仓库地址（购买时卖家提供）。
3. 在商店中找到 **HOMI** → 点击 **安装**。
4. 切换到 **配置** 页，按需填写配置项（授权码在面板内激活，见下文）。
5. **启动** HOMI，通过左侧栏 / **打开 Web UI** / 浏览器直连 `http://<HA主机IP>:8099` 进入。
6. 首次进入按引导完成初始化，在授权页复制申请码发给卖家换取授权码，粘贴激活。

后续有新版本时，商店中的 HOMI 卡片会直接显示 **更新** 按钮，一键完成升级。

## 配置项

| 配置项 | 说明 |
| --- | --- |
| `HOMI_LICENSE_PUBLIC_KEY` | 离线授权公钥。默认已内置公钥，可按需覆盖。 |
| `EZVIZ_APP_KEY` | 萤石云 AppKey，用于萤石摄像头代理。 |
| `EZVIZ_APP_SECRET` | 萤石云 AppSecret，用于萤石摄像头代理。 |

## 独立端口访问（默认开放，全屏场景）

默认入口是 HA 侧边栏 / 打开 Web UI（经 Ingress，带 HA 登录保护）。加载项同时默认在宿主机开放 `8099` 端口，装好即可用：浏览器直接访问 `http://<HA主机IP>:8099` 即可独立打开 HOMI，不经 HA 侧边栏，天然全屏，适合墙屏平板挂墙。

1. 浏览器访问 `http://<HA主机IP>:8099`（面板内 设置 → 系统配置 → 独立端口访问 中可直接复制该地址）。
2. 手机/平板可通过浏览器"添加到主屏幕"获得无浏览器边框的全屏体验（应用清单已是 standalone 模式）。
3. 可选保护：设置中开启独立端口 PIN 解锁后，直连访问需先输入 PIN（默认关闭）。

**安全提示**：未开启 PIN 时，局域网内任何设备都能直接打开独立端口。建议仅在可信家庭网络中使用，不要把该端口映射到公网。如不需要独立端口，可在加载项 **配置 → 网络** 中清空 `8099/tcp` 端口映射（恢复仅 Ingress 访问）。

## 使用前检查

- HOMI Add-on 已启动。
- 授权页显示的申请码已激活（授权码与设备指纹绑定）。
- 设置 → 系统配置 页显示 Home Assistant 连接状态正常。
- 摄像头实体已能在 Home Assistant 中正常播放。

## 功能

- 设备状态实时同步。
- 灯光、窗帘、空调、媒体、遥控、场景和房间控制。
- 首页设备运行统计（含电池电量统计），低电量设备主动上报。
- 可配置首页信息容器、天气详情和多端布局同步；动态背景可开关（低性能设备可关闭以省电降温）。
- Home Assistant 人员同步，本地头像替换。
- 摄像头播放：HA 原生 WebRTC 主路 + HLS 自动回落，支持萤石云代理。
- AI 助手：本地快速查询基于实时数据（随问随查），首页快捷查询标签按家庭设备情况智能推荐；支持 OpenAI-compatible 模型代理。
- 离线授权、设备指纹绑定和后端验签。
- 本机备份、下载备份、导入恢复和恢复前回滚快照。

## 权限说明

- `hassio_api` / `hassio_role: manager`：仅用于离线授权硬件指纹采集。Add-on 通过 Supervisor API 读取本机网络信息（`/network/info`）和系统信息（`/os/info`、`/host/info`），生成 sha256 哈希（截断）作为授权指纹因子；全部数据只在本机哈希、只在本机比对，授权码中只包含哈希值、不含 MAC 或 machine-id 原文，不上传任何信息。

## 数据与安全

- Add-on 通过 Supervisor 运行时令牌连接当前 Home Assistant，不要求用户创建或保存长期访问令牌。
- AI API Key 由 HOMI Core 加密保存，不返回前端。
- 客户端只读取连接和密钥的配置状态，不获取明文密钥。
- 安全 PIN 使用哈希保存。
- HOMI 应用备份不包含 HA Token 和 AI API Key 明文。

## 支持边界

HOMI 负责面板、Add-on 后端、授权、备份和自身集成问题。Home Assistant Core、第三方设备、网络、摄像头厂商云、AI 服务商额度和模型质量不属于 HOMI 直接维护范围。
