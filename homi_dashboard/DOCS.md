# HOMI Add-on

## 简介

HOMI 是一款运行在 Home Assistant 本地环境中的安全家庭控制面板，用于在一个界面中查看和控制家中设备，适配手机、平板、桌面及 HA 侧边栏等多种访问方式。

面板配置保存在安装它的 Home Assistant 主机上，完成一次初始化后，同一网络内的多台设备可共用这份配置。

## 安装

1. 打开 Home Assistant → **设置 → 加载项 → 加载项商店**。
2. 点击右上角 **⋮ → 仓库**，添加 HOMI 仓库地址（购买时由卖家提供）。
3. 在商店中找到 **HOMI** → 点击 **安装**。
4. **启动** HOMI。一般无需修改任何配置，保持默认即可。
5. 通过 HA 左侧栏 / **打开 Web UI** 进入。
6. 首次进入按页面引导完成初始化。授权相关操作请在面板内的授权页进行，如有问题请联系卖家。

后续如有新版本，商店中的 HOMI 卡片会显示 **更新** 按钮，点击即可升级。更新前建议先备份。

## 访问方式

HOMI 默认仅通过 Home Assistant Ingress（HA 左侧栏或“打开 Web UI”）访问，`8099` 独立端口默认关闭。

- 请优先使用 Ingress，它会沿用 Home Assistant 的登录和访问边界。
- 不要把 `8099` 映射到公网，也不要通过路由器端口转发或公开反向代理暴露 HOMI。
- 如确需独立 Core/LAN 访问，必须先配置 HOMI Core 配对令牌；敏感设备操作仍需安全 PIN。

## 主要功能

- 查看和控制已接入 Home Assistant 的设备（灯光、窗帘、空调、媒体等，以 HA 实际接入情况为准）。
- 首页设备运行概览（含电池电量等信息，以设备实际上报为准）。
- 摄像头画面查看（依赖 HA 摄像头实体本身的支持情况，实际效果因设备与网络环境而异）。
- AI 助手：支持本地规则应答，也可自行配置兼容 OpenAI 接口的模型服务（需自备服务与 Key）。
- 授权管理、配置备份与恢复。
- 多端布局与显示设置（含动态背景开关）。

功能的实际表现取决于你的 Home Assistant 环境、设备厂商与网络状况，无法逐一保证。

## 权限说明

- `hassio_api` / `hassio_role: manager`：仅用于授权校验所需的设备指纹采集。Add-on 通过 Supervisor API 读取本机网络与系统信息（`/network/info`、`/os/info`、`/host/info`），生成哈希值作为指纹因子；数据仅在本机处理，不上传。

## 数据说明

- Add-on 通过 Supervisor 运行时令牌连接当前 Home Assistant，不要求创建长期访问令牌。
- 在面板中填写的密钥类信息（如 AI Key、PIN）仅保存在本机，不以明文回传给前端页面。
